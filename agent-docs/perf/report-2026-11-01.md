## Decided, with the measurement (`decisions-2026-11-01.json`)

- **Grid virtualisation: not built.** Live `/` at 390×844 DPR 3, cache off, no eager forcing: 36 tiles
  mounted at load, 27 of them more than 1.5 screens below the fold, 3 of those 27 downloaded. After 10
  screens: 72 tiles, 5,816 DOM nodes (`lazy-loading-2026-11-01.json`). Native lazy loading and
  `content-visibility` already cover it.
- **Folder descriptions stay in the folder tree.** They are 111 KB of 210 KB, but the Add-to drawer edits
  them from that list. On home the tree has left the first frame; on a world address it costs ~35 KB
  on the wire.
- **The `?skip=` switch was not shipped.** It lived only in two detached refute worktrees, now removed.
- **Next: home LCP is the data chain.** The LCP element is the first grid tile (eager,
  `fetchpriority=high`); resource load delay 1,580 ms because its URL is known only after JS, auth and
  the first Convex frame. Server-rendering or preloading the first row is the next lever (architecture
  change, not started).
- **Next: `/tasks` review wall shifts** (CLS 0.113–0.209 on `main.lmw-wall`, 1.4 MB of images). The page
  changed after 30 Oct; no speed PR touched it.
- **Next: folder tree re-sent on agent saves.** Filing an asset patches `folders.memberCount`, so the
  210 KB tree is re-sent with each save (seen every ~2.5 s during an agent run). Serve counts apart
  from the tree.
